🤖 AI Slash Extension - Interactive Test

Test your AI extension by typing in the editor below. Use the slash menu to access AI commands.

📝 How to Test:

  • Click in the editor below and start typing
  • Type / to open the slash menu
  • You'll see both default BlockNote commands and AI commands
  • Select an AI command to test the functionality
  • Try different AI commands to see how they work

🧪 Test Commands to Try:

  • /explain - Explain selected text
  • /quiz-me - Generate quiz questions
  • /summarize - Summarize content
  • /diagram - Create diagrams
  • /translate - Translate text
  • /improve - Improve writing
