# Custom AI Slash Extension

This example demonstrates how to create and use a custom AI slash extension with BlockNote. It shows how to integrate external AI commands into the editor's slash menu.

**Try it out:** Type '/' to see the slash menu with custom AI commands like '/explain', '/quiz-me', '/summarize', and '/diagram'.

**Key Features:**

- Custom AI slash commands
- External AI integration
- Simulated AI responses
- Response logging
